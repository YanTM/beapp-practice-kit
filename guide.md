# A simple first session with BEAPP

Choose a small task you can finish. Read its rules, finish an attempt, and keep a note of the result.

## Choose your starting point

- Have little time? Try one Reaction Time attempt.
- Want to explore memory? Choose Number Memory or Visual Memory.
- Want to work with attention? Choose Stroop or Visual Search.
- Want to try thinking tasks? Choose Pattern Recognition or Mental Rotation.
- Prefer a session chosen for you? Open [Daily Training](https://brainexerciseapp.com/daily-brain-training/).

[Open the kit planner](https://yantm.github.io/beapp-practice-kit/). Times are estimates; you can stop or take a break.

## Reaction Time

1. Wait until the signal changes.
2. Then click or tap as quickly as you can.
3. Finish the attempt and read the result.

**Watch for:** An early click is a mistake. Keep the same device and input method when comparing attempts.

**Keep a note:** Write the response time shown by the test. Note early clicks separately.

[Open Reaction Time](https://brainexerciseapp.com/reaction-time-test/).

## Number Memory

1. Look at the number while it is visible.
2. When it disappears, type it from memory.
3. Submit your answer and continue as the test directs.

**Watch for:** Keep the digits in order. Record the recall result shown at the end.

**Keep a note:** Write the digits recalled result. Compare the same test and difficulty.

[Open Number Memory](https://brainexerciseapp.com/number-memory-test/).

## Stroop Test

1. Look at the ink color of the word.
2. Choose the answer that matches the ink color.
3. Ignore what the written word says.

**Watch for:** If “BLUE” is printed in red, choose red. Read accuracy together with speed.

**Keep a note:** Write correct answers as a percentage. Add the time to your notes if shown.

[Open Stroop Test](https://brainexerciseapp.com/stroop-test/).

## Visual Memory

1. Look at the highlighted cells.
2. Remember their positions after they disappear.
3. Select the cells you remember.

**Watch for:** Notice the whole pattern. Track incorrect selections as well as the amount recalled.

**Keep a note:** Write the cells recalled result. Keep difficulty consistent when comparing attempts.

[Open Visual Memory](https://brainexerciseapp.com/visual-memory-test/).

## Pattern Recognition

1. Look at the sequence or pattern.
2. Find what changes from one item to the next.
3. Choose the answer that follows the same rule.

**Watch for:** Check shape, number, position, and direction. If you miss an answer, revisit the rule.

**Keep a note:** Write correct answers as a percentage. Note the kind of rule you missed.

[Open Pattern Recognition](https://brainexerciseapp.com/pattern-recognition-test/).

## Visual Search

1. Read the target shown in the instructions.
2. Scan the items on screen for that target.
3. Choose the matching item using the test controls.

**Watch for:** Follow the current target carefully. Record time alongside accuracy if both are shown.

**Keep a note:** Write correct answers as a percentage. Keep target difficulty and device consistent.

[Open Visual Search](https://brainexerciseapp.com/visual-search-test/).

## Choice Reaction

1. Read which response belongs to each signal.
2. Wait for the signal to appear.
3. Choose the matching response.

**Watch for:** The right response matters as well as speed. Note incorrect responses separately.

**Keep a note:** Write the response time shown. Keep the task and conditions the same.

[Open Choice Reaction](https://brainexerciseapp.com/choice-reaction-test/).

## Mental Rotation

1. Look closely at the reference shape.
2. Imagine turning it without changing its shape.
3. Choose the option that matches after rotation.

**Watch for:** A mirrored shape is different from a rotated shape. Check the smaller details.

**Keep a note:** Write correct answers as a percentage. Note the shapes that were difficult.

[Open Mental Rotation](https://brainexerciseapp.com/mental-rotation-test/).

## Read your result and choose one next step

Use the same exercise, difficulty, device, and input method when comparing attempts. Read correct answers together with speed when both are shown. An interruption or an early click belongs in your notes.

Next time, repeat the same task to compare, explore another skill, or use Daily Training. A seven-day plan is a set of optional suggestions, not a requirement to practice every day.

The kit journal is separate from the app history. Export your journal as CSV to keep a copy. Return to the same browser to review your [BEAPP app progress](https://brainexerciseapp.com/trainer/progress/).

Results describe performance in specific tasks. They are not a medical assessment or a promise of changes in everyday abilities. [Read how results are calculated](https://brainexerciseapp.com/how-results-are-calculated/).
